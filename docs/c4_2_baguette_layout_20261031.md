# C4_2 바게트 최종 돌출: 배치 후보와 순서 진단

> 공유 결과는 [전체 진행 요약](ee_gear_checkpoint_20261102.md)과 [조합별 결과](ee_gear_coverage_results_20261102.json)에 정리했다. 이 문서의 `output/` 경로는 로컬 보관 자료이며 GitHub 업로드에 포함하지 않는다.

## 최신 상태

g의 30.566mm 최종 높이 돌출 후, 저장된 장면으로 정적 후보와 점유 원인을 조사했다. **현재 적층에서 선언된 방향 4개 × XY 120곳 × Z 16개 = 7,680개 표본 모두 기존 payload와 겹친다.** 가장 작은 최대 침투는 10.185mm다. 밀대와 거품기의 현재 자세가 함께 있으면 같은 결과가 발생한다.

밀대 배치 직후 실제 저장 장면에서는 g에서 실행 가능한 것으로 판정됐던 방향의 XY 43곳에 적어도 하나의 비중첩 Z 표본이 있었다. 거품기까지 넣은 뒤에는 0곳이다. 이는 순서를 점검할 근거이며, 빈 표본이 실제 파지·운반·안착 성공을 뜻하지는 않는다.

공통 정책 `configs/c4_2_packing_policy.json`이 시리얼→우유→밀대→거품기→바게트를 강제한다. LLM이 이번 실행에서 임의로 고른 순서나 Reasoner 제거의 직접 결과로 설명하면 안 된다. g 이후 공통 소스 변경은 없다.

별도 물리 순서 진단 `output/c4_2-order-diagnostic-20261031-a`는 **시리얼→우유→밀대→바게트→거품기**로 실행을 완료했다. **바게트는 최종 수납 유지, 마지막 거품기가 Y 17.984mm·Z 27.582mm 돌출하여 전체 목표 실패**다. 실행 시간 482.310초, M5 원응답 10개, 새 M5 토큰 400,097. 원래 정책 파일은 수정하지 않았다. 새 M2의 자동 순서 사전조건·파생 부분순서만 바꾸고 G_k/M4를 정상 재생성했으며 M4 SUCCESS, EE 교체 1회/모션 비용 24로 기존과 같다. M1, 기존 추정값·행동·배치 슬롯·물성·성공 기준은 유지한다. 이 실행은 입력 정책을 바꾼 진단이므로 a~g의 동일 frozen prefix 대조나 최종 ablation 성적에 합치지 않는다. M5는 새 응답이다.

## 입력과 검증 범위

- 원본: g의 `0014` 바게트 TRANSPORT 요청, `0013/grasp/final_state.npz`.
- 원래 qpos/qvel/ctrl에 요청의 모든 객체 pose와 로봇 joint pose를 맞춘 **정적 장면 재구성**. 전체 물리 checkpoint 재생이 아니다.
- 7개 객체 위치 오차 0, collision vertex 오차 0, geom 이름 일치. orientation 오차 최대 약 1.2e-16rad.
- XML 전체 해시는 다르므로 동일 동적 환경이라고 주장하지 않는다. 객체별 실제 충돌 형상을 별도로 검증했으며 원래 선호 위치의 겹침 점수 23.2757886mm는 정확히 재현됐다.
- NumPy matmul 경고를 보존했다. 각 선언된 회전의 vertex 변환은 독립 einsum과 최대 1.39e-17m 차이, 모두 유한값임을 확인했다.
- 기존 위치 해상도 5mm, 충돌 여유 5mm, 방향별 4,096 표본 상한 유지. 이 진단의 비중첩 점수 0은 기존 occupancy ranking 기준이며, 5mm의 모든 물체 간 거리나 지지 안정성을 인증하지 않는다.
- 정적 검사 API 호출 0, 실행 중인 원본 장면 배열과 원본 산출물 변경 없음.

## 선언된 방향 전수 표본

| 방향 인덱스 | XY 수 | XY당 Z 수 | 비중첩 Z가 있는 XY 수 | 최저 최대 침투 |
|---|---:|---:|---:|---:|
| 0 | 120 | 16 | 0 | 10.185mm |
| 1 | 120 | 16 | 0 | 18.342mm |
| 2 | 120 | 16 | 0 | 16.321mm |
| 3 | 120 | 16 | 0 | 16.169mm |

인덱스는 `_orientation_candidates`의 선언 순서다. g는 방향 0에서 손 해제 통로와 IK 통과. 방향 3은 원래 선호 XY에서 IK 0개, 방향 1·2는 손 해제 통로 충돌이었다. 이번 정적 확장 검사는 그 방향들을 실행 허용한 것이 아니다.

g 내부의 `packing_position_selection`은 `NO_CLEAR_REACHABLE_POSITION_KEEP_EXISTING`이다. 120 XY를 이미 검사했으므로 이번 결과만으로 XY 탐색 자체가 빠졌다고 볼 수 없다. 다만 공간이 없는 현재 적층을 유지한 채 위에서 놓는 경로가 최종 3D 포함에 실패했다.

## 무엇이 공간을 막는가

동일 7,680 표본의 접촉 깊이를 물체별로 기록했다. 물체를 실제로 제거하거나 다시 안착시키지 않고 점수에서 일부를 제외한 기여도 분석이다.

| 점수에 포함한 물체 | 비중첩 XYZ 표본 수 |
|---|---:|
| 시리얼 + 우유 | 3,387 |
| 시리얼 + 우유 + 밀대 | 261 |
| 시리얼 + 우유 + 거품기 | 33 |
| 밀대 + 거품기 | 0 |
| 4개 전체 | 0 |

이는 고정된 현재 pose와 제한된 방향/그리드에서의 결과다. 모든 연속 자세의 불가능 판정이나 순서 변경의 성공 증명은 아니다.

## 실제 이전 적층 자세 대조

각 시점의 `container_support_world.json`에서 주변 물체 pose를 가져왔다. 바게트와 로봇은 후속 g TRANSPORT pose를 유지한 혼합 정적 장면이므로 당시 상태의 동적 재생으로 해석하지 않는다.

| 실제 적층 시점 | 수납 물체 | 방향 0/1/2/3의 비중첩 XY 수 |
|---|---|---|
| 우유 PLACE 완료, 0006 | 시리얼·우유 | 120 / 90 / 120 / 104 |
| 밀대 PLACE 완료, 0009 | 시리얼·우유·밀대 | 43 / 0 / 31 / 40 |
| 거품기 배치 후, 바게트 TRANSPORT 요청 | 위 3개 + 거품기 | 0 / 0 / 0 / 0 |

처음 `after-milk-...-a`는 0005(우유 TRANSPORT)를 잘못 골라 우유가 수납된 상태가 아니었다. `scope_correction.json`으로 제외 사유를 남겼고, **0006을 사용한 b만 위 표에 반영**했다. 잘못 고른 입력과 산출물도 보존했다.

## 근거 파일

모두 이 worktree 기준 `output/` 아래에 있다.

- `c4_2-baguette-layout-diagnostic-20261031-a`: manifest, 원래 선택 근거, 재구성 점검, 방향별 전체 표본·요약.
- `c4_2-baguette-blockers-20261031-a`: 객체별 충돌 형상 검증, pairwise_samples, blocker_subsets, 공통 소스 보존 확인.
- `c4_2-baguette-after-milk-20261031-b`: 올바른 우유 배치 완료 상태의 정적 비교.
- `c4_2-baguette-after-rolling-pin-20261031-a`: 밀대 배치 완료 상태의 정적 비교.
- `c4_2-order-diagnostic-20261031-a`: 정책 순서 변경을 명시한 input_difference, 새 정책, M2/G_k/M4, 실제 제어기 실행과 API 원응답.

이번에는 공통 구현을 추가 수정하지 않았다. 앞선 391 passed/2 skipped는 g 코드의 회귀 결과이고, 이번 검증은 별도 진단의 입력·형상·재현·보존 assertion이다. w/o Reasoner의 기존 M2 거절 및 다른 7개 태스크의 남은 작업은 그대로다.

## 순서 진단 최종 결과

- `diagnostic_result.json`에 최종 상태·입력 보존·실패 분류·접촉-장면 해시 검증을 저장했다. 실행 중인 실험 없음.
- 바게트는 XY 후보 17개 검사 후 원래 자리에서 8.563mm 이동한 비중첩·IK 유효 위치 선택. 배치 직후 수납/해제/지지 통과. 지지 경로는 baguette→rolling_pin→milk→packing_box였다.
- 이후 거품기를 배치한 최종 상태에도 바게트는 수납 유지했다. 밀대·시리얼·우유도 수납 유지.
- 마지막 거품기는 35개 XY를 검사했으나 비중첩 후보가 없어 기존 위치 유지. 검사한 후보의 최저 침투는 21.909mm였다. 5.02초 안착 관측 후 움직임은 충분히 줄었지만 Y 17.984mm, Z 27.582mm 돌출했다.
- `CONTAINER_NOT_SETTLED`/goal 실패. 팔 위치 오차 0.00693mm, 손 접촉 0, 부착 없음, 팔 정체 조기 중단 없음. 뚜껑 미실행, 전체 목표 실패.
- 순서가 갈라지기 전 밀대 배치 완료의 5개 payload 위치는 g와 정확히 일치했고 회전 오차는 수치 오차 수준이었다. `common_prefix_pose_comparison.json`에 보존. M5 응답은 여전히 새로 생성한 것이므로 완전한 고정 응답 재생이라고 표현하지 않는다.
- 공통 소스·정책 파일 변경 없음. 원래 M1 입력과 진단용 M2도 실행 전후 해시 유지. 이 진단의 순서 교환을 공통 정책 수정으로 승격하지 않았다.
- 결론: **순서만 교환하면 실패 대상이 바게트에서 거품기로 이동한다.** 두 물체의 수납을 함께 만족시키는 긴 물체 배치 방향·XY 조합이 다음 진단 대상이다. 동일 조건에서 무작정 기다리거나 성공 허용치를 늘리는 조치의 근거는 없다. 현재 제한된 후보의 실패를 모든 포장의 물리 불가능으로 일반화하지 않는다.
