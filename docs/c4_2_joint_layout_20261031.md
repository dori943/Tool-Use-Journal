## 최소 바닥 면적 a 종료와 공통 계측 수정

a는 300.674초, M5 원응답 6개로 종료했다. M1/M2/G_k/M4와 소스는 실행 중 보존됐다. 시리얼과 우유는 실제로 세워져 수납됐고, 밀대도 3D 수납·안착·해제를 통과했으나 `PLACEMENT_GOAL_NOT_SATISFIED`로 지지 검사에서 중단했다. 최종 전체 목표는 실패다.

밀대는 상자 옆벽 3곳과 접촉했고, 기록된 법선력은 2.387/2.992/2.578N이지만 법선의 위쪽 성분은 거의 0이었다. 기존 `measure_contacts`는 `force[0] * normal_z`만 위쪽 힘으로 기록하여 **접선 마찰력을 버렸다**. 이전 원응답에는 접선 힘이 없어 a를 사후 성공으로 바꾸지 않는다.

MuJoCo의 contact force는 접촉 좌표계의 3차원 힘이며 contact.frame에는 축이 행으로 저장된다. [MuJoCo 공식 설명](https://mujoco.readthedocs.io/en/latest/programming/simulation.html)에 맞춰 전체 힘을 world frame으로 변환하고 target 쪽 부호를 적용했다. 새 출력은 `force_on_target_world_n`, `force_basis=FULL_CONTACT_FORCE_WORLD`, `normal_upward_force_n`을 함께 기록하며 `upward_force_n`은 전체 힘의 수직 성분이다.

실제 소형 물리 장면에서 0.1kg 물체를 수직 벽 마찰이 지지할 때 법선 위쪽 힘은 0, 전체 위쪽 힘은 약 0.981N으로 재현했다. 물체 쌍을 뒤집으면 힘 부호가 반대가 되고, 회전된 벽에서도 결과를 확인했다. 마찰 없는 condim=1 벽에서는 위쪽 힘 0으로 떨어지는 물체를 지지로 인정하지 않는다. 기존 침투·부착·robot·사이클·오래된 장면 증거 검사도 유지했다.

관련 70 tests passed: placement_contacts, container_support, container_settle, planning_preservation, task_goal_evaluation. 결과는 a/contact_force_regression.xml. 공통 코드 변경은 접촉 계측과 지지 함수 설명 및 관련 테스트이며, 이 변경은 Full/w/o Reasoner 공통이다. 기존 task-goals-v1 최종 목표와 물성·힘·성공 허용치는 변경하지 않았다.

새로운 실제 upright 바닥층으로 같은 4방향 공동 탐색(d)을 수행했지만, 선언된 자세와 5mm 상자 여유에서 시리얼·우유·상자와 비중첩인 개별 긴 물체 후보가 0이었다. 실제 밀대가 안착한 자세와는 다를 수 있으며 물리 불가능을 뜻하지 않는다. 이 정적 결과로 실제 실행을 성공/실패 처리하지 않는다.

c의 마지막 프레임과 영상, 최종 형상/접촉 world 해시/API 감사는 c/diagnostic_result.json, final_frame.png, video_audit.json, full/c4_2/seed_0/m5/c4_2.mp4에 있다. 영상 검사는 마지막 프레임만 수행했으며 전체 프레임 무결성 검사로 표현하지 않는다.
