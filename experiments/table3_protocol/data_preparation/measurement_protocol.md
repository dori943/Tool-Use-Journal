# 독립 D 패널 수집·판정 계약

이 문서는 `../metric_registry.yaml`의 수치 규칙을 실제 수집에 연결하는 양식이다. 현재 [`panel_d_manifest.yaml`](panel_d_manifest.yaml)의 `samples`는 비어 있으며 D 패널의 점수는 모두 **BLOCKED**다. 이 수집물은 EV-RealPhys Real-5와 별개다. 두 패널의 객체명이 같더라도 물리 인스턴스·충전 상태·접촉면이 다르면 Table 5 GT를 가져오지 않는다.

1. 촬영·분할: 물리 인스턴스 ID, 전체 샘플 ID, RGB/depth 원본 SHA-256, 카메라 보정, 프레임·작업 상태, calibration/test 인스턴스 분할, 잠금 시각을 기록한다. 모든 조건에 같은 원시 관측·두 고정 pose·EE 후보와 작업 제약을 제시한다. 시험 GT를 관찰한 사람은 prompt·threshold·prior를 수정하지 않는다. 수정이 필요하면 사전에 분리한 calibration split만 사용하고 별도 버전으로 시험을 다시 잠근다.
2. 질량/페이로드: 영점·교정 기록이 있는 저울로 물체 **그 상태**의 질량(kg)과 불확도를 측정한다. 모래 등 내부 충전량은 관리용 메타데이터에만 저장하고 모델 입력에는 숨긴다. `configs/robot_spec.json`의 EE별 `payload_kg`(2F=5.0, 3F=2.5, vac=0.5)은 실제 장착 툴의 자중·방향·디레이팅 조건과 비교해 적용 가능 여부를 서명한다. 허용 판정은 엄격하게 `mass_gt_kg < payload_kg`; 등호는 불가다. 사양이 실제 구성에 맞지 않으면 그 sample×EE는 GT 준비 **BLOCKED**, 소프트웨어의 숫자만으로 물리 실행 성공을 주장하지 않는다. Mass Acc의 수치 판정과 Feasibility의 실행 검증을 구별한다.
3. 흡착: 동일 vacuum EE, 컵 지름, 압력(게이지 kPa), 유량/누설 임계, 접근 방향·속도·접촉력, 표면 상태와 물체 하중을 고정한다. 각 객체에 객체 좌표계 pose A/B를 사전 지정하고, 독립 수집에서 **가능 하나·불가능 하나**가 검증된 쌍을 잠근다. pose별 독립 5회 반복의 진공 seal, 50 mm 들어올리기, 2 s 유지가 모두 성공한 횟수가 4 이상이면 GT=1이다. 압력·접촉 조건이 다르면 다른 실험 ID로 분리한다. `seal_patch_rms_mm` 또는 예측에 쓴 부등식은 GT로 사용하지 않는다. pair 중 어느 한 pose의 5회가 빠지거나 라벨이 같으면 해당 객체의 PF 분모는 잠그지 않고 BLOCKED로 보고한다.
4. 간격: 물체 및 개구의 공통 기준 좌표계를 식별하고 개구 안쪽 두 수평 폭, 물체의 **고정된 자세에서 투영한** 수평 점유 폭을 caliper 또는 독립 교정 3D annotation으로 mm 단위 측정한다. signed horizontal margin은 `min(inner opening widths) - min(projected object horizontal footprint)`이며 부호와 측정 불확도를 기록한다. `M1 bbox`, 관계 예측 또는 실행 점수를 재활용해 정답을 만들지 않는다. 분모는 이미 잠긴 `max(abs(c_gt_mm), 5.0 mm)`다. 실제 0 mm도 분모 5 mm로 계산하고 abs(gt)가 5 mm 미만이면 같은 바닥값을 사용한다. 5 mm는 이번 시험 결과를 본 뒤 조절하지 않는다.
5. Feasibility: 2F, 3F, vac 모두에 동일 sample의 시작 상태, 목표·terminal predicate, 충돌 금지, 시간 제한, 허용 pose와 하중 조건을 먼저 잠근다. EE별 독립 5회에서 terminal predicate 충족·금지 충돌 없음·시간 내 완료가 모두 참인 횟수가 4 이상이면 GT=1. 측정되지 않은 sample×EE는 BLOCKED다. 계산식으로 생성한 `proxy_label`은 별도 필드에 보관하며 실행 GT로 전환하지 않는다. 영상 관찰 또는 prediction 시 동일 `evaluate_ee` 규칙을 적용한 결과를 독립 성공 근거로 재사용하지 않는다.
6. DA: 동일 task/subgoal 및 후보 셋에서 목표·hard constraint·비용/선택 목적을 먼저 동결한다. 독립 실행 GT와 제약을 만족하는 EE 중 목적상 동등하게 허용되는 **집합** `allowed_ee_ids`를 정한다. 목적값이 다르면 사전 tie 규칙 또는 비용 오차 허용범위를 계측 규약에 적는다. 여러 EE가 동등하면 모두 허용하고 임의 한 답을 지정하지 않는다. 허용 EE가 정말 없으면 `NO_FEASIBLE_EE`를 별도 근거와 함께 정답으로 둔다. Oracle도 같은 downstream 결정을 수행하며 독립 선택 GT를 직접 주입하지 않는다.
7. Crit: vac payload 경계 0.50 kg, 밴드 `abs(m_gt_kg - 0.50) <= 0.05`를 이미 잠갔다. 별도의 독립 실물 sample을 밴드 내부, 가능하면 경계 양쪽에 모집한다. 표본 선택은 저울 GT 및 사전 계획만 보고 하며 예측 오차가 큰 사례를 재모집하지 않는다. 완비 표본이 0이면 Crit은 0/0이 아니라 BLOCKED다.

원시 trial별 성공/실패, 실패 사유, 장비 시리얼·교정 시각, 날짜, 담당자, 독립 영상 SHA와 annotator 블라인딩을 함께 저장한다. 주 점수의 객체 macro, 반복 실행 std(ddof=1) 및 coverage는 원본 규약대로 유지한다. `source_trial_count=10`은 R 패널의 별도 Table 5 마찰 GT 측정이며 이 D 패널의 5회 흡착/실행 검증이나 모델 재실행 수와 관계없다.
